Connect AI assistants to Seasons

With Seasons Pro, an AI assistant that supports the Model Context Protocol (MCP), such as Claude or ChatGPT, can read your plan, answer "what if" questions about budgets and watchlists, and, if you allow it, update your watchlist and planning preferences.

Seasons never asks you to sign in on the web. You approve every assistant from the Seasons app, and you can revoke it there at any time.

Server address

https://api.getseasons.app/mcp

Assistants that sign in with OAuth

  1. Add Seasons as a custom connector or MCP server using the address above.
  2. When the assistant opens a Seasons page, it shows a pairing code.
  3. In the Seasons app, open Settings, select AI Agents, then Enter pairing code.
  4. Check the assistant's name and where it returns, choose read-only or read-and-change access, and approve.

Only approve a code shown on a page you opened yourself.

Assistants that use an access key

  1. In the Seasons app, open Settings, select AI Agents, then Create access key.
  2. Copy the key. Seasons shows it only once.
  3. Configure the assistant to send it as Authorization: Bearer <key>. For Claude Code: 
    claude mcp add --transport http seasons https://api.getseasons.app/mcp --header "Authorization: Bearer <key>"

What an assistant can do

  • Read your plan, subscriptions, watchlist, and planning preferences.
  • Preview plan changes without changing anything.
  • With read-and-change access: apply previewed changes and add or remove watchlist titles.

An assistant can never start, cancel, or pay for a streaming subscription. If your Seasons Pro subscription ends, connected assistants stop working until it is renewed.
