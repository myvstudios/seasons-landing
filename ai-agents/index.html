Connect AI assistants to Seasons

With Seasons Pro, an AI assistant that supports the Model Context Protocol (MCP), such as Claude or ChatGPT, can read your plan, answer "what if" questions about budgets and watchlists, and, if you allow it, update your watchlist and planning preferences.

You approve every assistant yourself, in the Seasons app or on Seasons Web, and you can revoke it from either at any time. The page an assistant opens never asks for your password.

Server address

https://api.getseasons.app/mcp

Assistants that sign in with OAuth

  1. Add Seasons as a custom connector or MCP server using the address above.
  2. When the assistant opens a Seasons page, choose Sign in to approve in this browser and sign in to Seasons Web. Or, in the Seasons app, open Settings, select AI Agents, then Enter pairing code and type the code the page shows.
  3. Check the assistant's name and where it returns, choose read-only or read-and-change access, and approve.

Only approve a connection you started yourself, from a page you opened. Seasons will never ask you to share a pairing code. Apps that Seasons has registered as partners are marked as verified; any other name is chosen by the app itself.

Assistants that use an access key

  1. On Seasons Web, or in the Seasons app under Settings, AI Agents, choose Create access key.
  2. Copy the key. Seasons shows it only once.
  3. Configure the assistant to send it as Authorization: Bearer <key>. For Claude Code: 
    claude mcp add --transport http seasons https://api.getseasons.app/mcp --header "Authorization: Bearer <key>"

What an assistant can do

  • Read your plan, subscriptions, watchlist, and planning preferences.
  • Preview plan changes without changing anything.
  • With read-and-change access: apply previewed changes and add or remove watchlist titles.

Automated assistants can ask Seasons to notify a web address they run when your plan changes. The Seasons app and Seasons Web show which address each connection notifies; revoking the connection stops it.

Seasons Pro is available in the Seasons app for iPhone and Android. An assistant can never start, cancel, or pay for a streaming subscription. If your Seasons Pro subscription ends, connected assistants stop working until it is renewed.
